# Developer Portfolio

Responsive personal portfolio for Islam Chaachaa, presenting academic projects, technical skills and practical web-development work.

## Highlights

- Responsive single-page layout
- Project descriptions with real screenshots and recorded demonstrations
- Skills and contact sections
- Lightweight implementation using HTML, CSS and JavaScript
- Published with GitHub Pages

## View the portfolio

[islych.github.io/portfolio](https://islych.github.io/portfolio/)

## Run locally

Clone the repository and open `index.html` in a browser. No build step is required.

```bash
git clone https://github.com/islych/portfolio.git
cd portfolio
```

## Project media

The `image/` and `videos/` directories contain screenshots and demonstrations captured from the projects presented on the site.
